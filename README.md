
# Addis Weather App
**Description:** A mobile app built with Flutter that fetches live current weather conditions for Addis Ababa from the Open-Meteo API.
**Problem Solved:** Helps users view real-time climate and wind variations instantly.
**Main Features:** API Integration, Clean Architecture, Dark UI Theme, Hourly Forecast layout.
